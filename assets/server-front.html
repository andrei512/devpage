Publish a document. Get a link.

Docs, slides and designs from Markdown in your repository, published from the CLI. Every version is kept, comments carry over from one to the next, and every open page updates when you publish again.

Publish from your repository

  1. Install the CLI

    cargo install devpage

  2. Connect it to this server

    devpage context add work {{server}}
devpage context use work

  3. Publish. It prints the link; publishing the same file again adds a version.

    devpage publish docs/devpage.yml

Then

devpage list
The documents you've published here, with their links.
devpage versions <id>
Every version: who published it, and when.
devpage comments <id>
Readers' threads, with the quote each is on: for you or your agent to act on.
devpage download <id>
A PDF of a doc or slides, a PNG of a design.
--json
Each of these takes it, for an agent to read.

HTTP API

POST/api/documentsA zip: creates a document.
POST/api/documents/<id>/versionsA zip: adds a version.
GET/api/documents/<id>The document and its versions.
GET/api/documents/<id>/commentsIts threads.
DELETE/api/documents/<id>It, its versions and its comments.
