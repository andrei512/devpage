# PDF

`devpage pdf` has Chrome print a doc or a deck exactly as the browser shows it:
a doc on A4 with its header and footer — this catalog prints that way — and a
deck one 16:9 slide per page.

<Terminal>

```
$ devpage pdf docs/features
devpage features.pdf
```

</Terminal>

Teaches it: [Printing to PDF](../boxes/viewer/pdf/README.md).
