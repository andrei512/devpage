# Navigation and themes

A site gets a sidebar from its pages' Topics sections and, optionally, a
navbar of links, dropdowns and icons; every page has a light/dark switch, and a
`logo` puts an image before the title and in the browser tab.

```yaml
logo: logo.svg
navbar:
  Docs (book-open): README.md
  (github): https://github.com/andrei512/devpage
```

Teaches it: [Making a site](../boxes/viewer/making-a-site/README.md),
[Organizing navigation](../boxes/viewer/organizing-navigation/README.md),
[Choosing a theme](../boxes/viewer/diagrams-and-themes/README.md#choosing-a-theme).
