# The live session

Talk over your pages while coding agents work. With `DEVPAGE_OPENAI_API_KEY`
set, or an Azure OpenAI resource named, and its program installed, every page devpage serves on this computer
shows an orb: press it and speak. The session's tasks open in a panel, and
its scratch pads are drawn over the page you are reading.

<Terminal>

```
$ devpage setup
$ DEVPAGE_OPENAI_API_KEY=sk-... devpage docs
```

</Terminal>

Teaches it: [The live session](../boxes/viewer/live-session/README.md).
