# Add an opt-in affected-test command

Pin Nx and its development toolchain at the repository root. Provide three developer operations through one supported entry point: explain a diff, run affected browser checks, or request the full browser checks. Nx evaluates target inputs. The runner translates selected targets to Rust test filters and runs their union in one Cargo invocation. Bootstrap this with video, slide PNG and a broad remaining group.

## Acceptance

- Local selection can compare against a base and include staged, unstaged and relevant untracked files. Explicit base/head mode evaluates the same committed diff on developer machines and CI.
- Explain identifies changed inputs, selected suites and the reason for a broad fallback. An empty selection exits successfully before spawning Cargo or Chrome. An invalid selector configuration fails visibly.
- A broad run shares the compiled binary and browser harness. Apply each platform’s existing flags. A focused Windows run respects its GPU exclusions while a capable local machine can exercise GPU tests.
- The pilot uses the existing Cargo cache and executes selected browser tests afresh. Installing the product with Cargo and building the release image need no Node dependency. Verify Git, Docker context and published package contents exclude generated tooling and caches.
