# 0.1.0

Released 25 October 2026 — the first release, published to crates.io and
tagged `v0.1.0`.

## Three kinds of document

A YAML document file's `kind` says what it describes: a **site** of pages with
a sidebar built from Topics sections, a **doc** of chapter files read as one
page with an outline, or **slides**, one Markdown file per slide on a
1920 × 1080 stage. A lone Markdown file is a doc.

## What came with it

- **The served folder** — the folder devpage starts from, or `--root` — is the
  boundary: documents link to each other and to files beside the code.
- **Live updates** of every open page when a file changes; a site's `watch`
  list narrows what refreshes.
- **Comments** on text or paragraphs, one thread per file in a self-ignoring
  `.devpage/` folder; the author comes from git, or from an auth proxy's
  header when deployed.
- **Checked links**, in the preview and with `devpage check`.
- **`devpage pdf`**, Chrome printing a doc or a deck exactly as it shows.
- **Deploying**: `--host`, `--port`, `--user-header`, and an example image.
- MIT licensed; Rust 1.89 or later.
