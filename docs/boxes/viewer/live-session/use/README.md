# Use it

What you do to have [the live session](../README.md) on your own projects:
install it and give it a key, say in plain words which coding agent gets
which kind of work, and change its settings.

## Topics

- [Turn it on](turn-it-on/README.md) — install the program, give it a key,
  and serve your project. Also when the session is on, and how to turn it off
  for one project.
- [Routing](routing/README.md) — which coding agent and which model a piece
  of work goes to: what is enabled, your rules, and what you say.
- [Settings](settings/README.md) — every setting, where a session's data is
  kept, and recording your voice.
