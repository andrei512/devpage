# Share

How a document reaches other people: comments on its pages, a PDF, a narrated
video, a deployment for a team, and a server that keeps every published
version. It is a part of the [viewer](../README.md).

## Topics

- [Comments](comments/README.md) — commenting on text or a paragraph, replying,
  resolving, and the files a thread is kept in.
- [Printing to PDF](pdf/README.md) — `devpage pdf`, the Chrome it drives, and
  why the PDF matches the screen.
- [Making a video](making-a-video/README.md) — `devpage video`, its narrator,
  writing notes to be read aloud, how a deck is recorded, and its silence
  rules.
- [Deploying devpage](deploying/README.md) — the example image, the auth proxy
  that names readers, and trying it with Docker Compose.
- [Server mode](server/README.md) — `devpage server`: documents published as
  zips, their versions, the CLI's contexts, the API, and storage in SQLite, a
  bucket and a bounded cache.
