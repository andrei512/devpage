# Process

Work done toward one objective, written for an agent to follow. `## When`
says what starts it — a schedule, an event or a person asking — and whether
an agent runs it alone or in a session with a person. `## Steps` are what to
do, in order, with where each number is read. `## Report` says what to tell
whom, and what to do when the objective is missed. It sits under the
objective it works toward.
