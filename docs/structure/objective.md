# Objective

A requirement with a number: a value the system must reach or stay within,
measured by a benchmark or read from a data source outside the repository.
`## Why` gives what goes wrong when the number is missed; `## Check` says
where the number comes from and how to read it. The work done toward it is
in the process pages under it. It may sit under any page.
