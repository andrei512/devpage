# Constraint

A requirement a test can check: something the system must do, or must never
do, stated in one sentence. Tests point at it by its id, the file's name
without `.md`; it is met when at least one test points at it and every one of
them passes. `## Why` gives the failure it prevents; `## Check` says what the
tests show. It may sit under any page.
