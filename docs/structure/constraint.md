# Constraint

A requirement a test can check: something the system must do, or must never
do, stated in one sentence. Its front matter gives it an `id`, and tests
point at it by that id; it is met when at least one test points at it and
every one of them passes. `## Why` gives the failure it prevents; `## Check` says what the
tests show. It may sit under any page.
